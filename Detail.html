Website Portofolio Pribadi

Proyek pembelajaran pengembangan website statis.

Tentang Proyek

Website portofolio pribadi ini dirancang sebagai media untuk memperkenalkan identitas, pendidikan, kemampuan, dan hasil pengerjaan proyek. Website memiliki navigasi ant halaman yang jelas dan tampilan responsif.

Tujuan Pembuatan

  • Menerapkan struktur HTML yang semantik.
  • Menggunakan CSS untuk memperindah tampilan.
  • Menggunakan Bootstrap 5 untuk layout responsif.
  • Menerapkan JavaScript untuk validasi form login.
  • Mempraktikkan navigasi ant halaman website.

Teknologi yang Digunakan

HTML5 CSS3 Bootstrap 5 JavaScript
